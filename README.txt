# FishingBazaar static website

A premium, responsive, multi-section "Coming Soon" website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a browser. An internet connection is needed for Google Fonts and the remote Unsplash images.

## Before publishing
1. Replace `hello@fishingbazaar.com` in `index.html` with your active business email.
2. Add your WhatsApp number / phone number and social links when ready.
3. Replace the sample category photos with your own product photos as they become available.
4. Confirm that you have permission to use all photos and review any third-party image-provider terms.
5. Upload the three website files (`index.html`, `styles.css`, `script.js`) to your hosting provider's public web root (often `public_html`).

This is a static informational website. It does not yet include a shopping cart, product inventory, online payments, customer accounts, or order management.
